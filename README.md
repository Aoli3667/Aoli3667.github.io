# Allan Tsai — Portfolio

A bilingual (English / Traditional Chinese) game-development portfolio built with Astro and deployed to GitHub Pages.

雙語（英文／繁體中文）遊戲開發作品集，使用 Astro 建置並透過 GitHub Pages 發布。

## Local development

```sh
pnpm install
pnpm dev
```

## Validation

```sh
pnpm build
```

The build checks Astro/TypeScript diagnostics, generates the static site, verifies every localized route, and rejects accidental local file paths.
